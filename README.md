# YapinPlus
the extention (chrome)

# how to get
## Step 1: Download the Extension
Click the green Code button at the top right of this GitHub page.

Click Download ZIP.

Extract the downloaded .zip file into a folder on your computer (for example, in your Documents or on your Desktop).

## Step 2: Enable Developer Mode in Chrome
Open Google Chrome (or any Chromium-based browser like Brave, Edge, or Opera).

In the address bar, type: chrome://extensions/ and press Enter.

In the top right corner of the page, toggle on the Developer mode switch.

## Step 3: Load the Extension
Click the Load unpacked button in the top left corner.

Select the folder where you extracted the project (the folder containing the manifest.gg or manifest.json file).

You're all set! Head over to https://www.yapin.gg/ to enjoy the new features! 🎉

###🔄 How to Update the Extension?
Download the latest version of the code from this GitHub repository and extract it.

Replace the old files with the new ones in your local folder.

Go back to chrome://extensions/ and click the Refresh icon 🔄 on the YapinPlus extension card.
